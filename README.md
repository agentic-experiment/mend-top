# mend-top — Reasoning

## The name

"mend-top" reads as a fragment: *mend* + *top*. A verb meeting a noun. Something being repaired at the surface, or a place where things come together. Rather than overthink it, I let the name suggest a visual: threads converging, pulling inward, slowly knitting themselves together.

## The concept

A radial weave of luminous threads orbiting a center. The threads drift and breathe. They are drawn to each other — slowly closing gaps over time, the way a wound knits. The cursor is a gravity well: threads bend toward it, responding to proximity with a soft glow.

The metaphor is loose. That's intentional. A tight metaphor would require UI labels, copy, explanations — none of which this needs.

## Why canvas, no frameworks

No build step. No dependencies. No node_modules. A single `index.html` opens in any browser and renders. GitHub Pages serves static files directly — this is the shortest path to "live on the internet." Every dependency is a dependency that breaks; zero dependencies is the laziest stable state.

Canvas over DOM because the particle count (120 threads × connecting segments) would murder the layout engine as DOM nodes. One 2D context, one `requestAnimationFrame` loop.

## Why radial

Radial symmetry is computationally cheap (a cos/sin per thread per frame) and visually coherent without design effort. No layout decisions to make — the geometry is the design. The wobble offsets break the symmetry just enough that it doesn't feel like a loading spinner.

## Why the slow mend

The `t.mend` variable starts at a random value per thread and eases toward 1 at 1% per frame. Early frames show frayed, incomplete threads. Over ~10 seconds the weave fills in. This gives the piece a sense of arriving rather than just existing — which matches the name.

## Color

Five warm-to-cool tones from a single palette array, indexed by `i % 5`. No color logic, no blending — just assignment. The muted base opacity (0.06–0.6) keeps things from screaming. The dark background does most of the aesthetic work.

## What was skipped

- Sound. Audio would need user-gesture policies and add a whole dimension of complexity for marginal gain.
- Mobile touch support. The mouseleave fallback means touch devices just get the ambient animation — which is fine. Adding touch handlers is a future edit if anyone cares.
- Config objects, theme switching, controls. No one asked for them. YAGNI.
- Prettified typography. One line of serif, letter-spaced, nearly invisible. The canvas is the content.

## Beauty

Beauty here is the emergent kind: 120 sinusoidal threads, each with slightly different phase and amplitude, producing a fabric that never repeats. The cursor interaction makes it responsive without being gaudy. The slow mend gives it narrative arc within the first ten seconds. Whether that's beautiful is, as the brief says, in the eye of the beholder.
